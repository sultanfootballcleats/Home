# HOW IT WORKS
# Each product is a block of "Label: value" lines. One blank/dashed line
# ("----------") separates one product from the next. Just copy a whole
# block (from "Product ID:" down to the line of dashes after it), paste it
# above or below, and edit the values for the new pair.
#
# Any line starting with "#" (like these) is just a note and is ignored —
# feel free to leave them or delete them.
#
# FIELD GUIDE
#   Product ID     — must be unique for every pair, e.g. p1, p2, p3...
#                     If you're adding a new pair, use the next free number.
#   Name           — shoe name, e.g. NIKE Phantom GX
#   Brand          — e.g. NIKE, ADIDAS, PUMA
#   Category       — must be exactly one of:
#                       adult-studs
#                       kids-studs
#                       adult-grippers
#                       kids-grippers
#                       accessories    (shin guards, socks, bags, etc — anything
#                                       that isn't studs or grippers footwear)
#                     Note: the shop's Category filter only shows Adults /
#                     Kids / Accessories, and the separate Type filter shows
#                     Studs / Grippers — so "adult-studs" shows up under both
#                     "Adults" and "Studs" automatically, you don't need to
#                     pick between them.
#   Tag            — small badge on the card, e.g. Like New, Best Deal.
#                     Leave blank for no badge.
#   Color          — e.g. Black & White
#   Size US / UK / EUR — this pair's one size (every pair is a single unit)
#   Condition (out of 10) — a number 1–10. This is what turns into the
#                     star rating shown to customers (10 = 5 stars,
#                     9 = 4.5 stars, 8 = 4 stars, and so on).
#   Fault          — write "None" if there's nothing to note, or a short
#                     honest note like "Slight scuffing on the toe"
#   Price (PKR)    — the selling price in rupees, just the number
#                     (e.g. 3900 — no "Rs." or commas)
#   Original Price (PKR) — the crossed-out "before" price, if any.
#                     Leave blank if there isn't one.
#   Image          — file path to the photo, e.g. assets/products/p2.jpg
#                     For MULTIPLE ANGLES, list several paths separated by
#                     commas on this same line, e.g.:
#                       Image: assets/products/p2.jpg, assets/products/p2-side.jpg, assets/products/p2-sole.jpg
#                     The first one is used as the card/thumbnail photo; all
#                     of them appear as clickable thumbnails on the product
#                     page. (See assets/products/README.txt for how to add
#                     the actual photo files.)
#   Video          — file path to a video, or leave blank
#   Description    — one honest sentence about the shoe. Don't repeat the
#                     condition here — the star rating already shows that.
#
# When you're done editing, just save this file. Refresh the website and
# your changes are live — nothing else to touch.
